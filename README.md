# Cat-Dog-Image-Classification
at and Dog Image Classification

Project Overview

This project is based on Machine Learning and Image Classification. It identifies whether an uploaded image belongs to a Cat or a Dog.

The model was created and trained using Google Teachable Machine.

Model Information

Model Name: tm-my-image-model

Input Image Size: 224 × 224 pixels

Classification Classes: Cat and Dog

Model Architecture: MobileNet-based

Output Layer: Softmax

Export Format: TensorFlow.js

Trained Model Files

The exported model contains:

model.json – Model architecture and configuration.

weights.bin – Trained model weights.

metadata.json – Model information and class labels.

Project Methodology

Downloaded the dataset from Kaggle.

Organized images into Cat and Dog classes.

Created an image classification project in Google Teachable Machine.

Uploaded the dataset images.

Trained the machine learning model.

Tested the model using sample images.

Exported the trained model in TensorFlow.js format.
